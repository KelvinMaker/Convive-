# **App Name**: Convive+

## Core Features:

- Registro de Incidentes: Permitir a los usuarios registrar incidentes de convivencia (conflictos o logros) de forma anónima o identificada.
- Roles de Usuario: Clasificar los usuarios en diferentes roles: estudiante, docente y directivo. Dependiendo del rol, permitir o denegar acceso a los datos del sistema. 
- Grupos de Usuarios: Implementar la creación de grupos de usuarios, donde los miembros puedan compartir y visualizar los mismos registros de convivencia.
- Resúmenes IA de Incidentes: Generación automática de resúmenes de incidentes. Usar una IA tool que genere resúmenes concisos a partir de los reportes ingresados, identificando patrones y tendencias en el comportamiento de los incidentes reportados.
- Panel de Monitoreo en Tiempo Real: Panel de control que muestre métricas clave sobre la convivencia escolar en tiempo real, como el número de incidentes reportados por tipo, la frecuencia de los conflictos, los grupos más afectados, etc.

## Style Guidelines:

- Color primario: Azul moderado (#5DADE2) para transmitir confianza y seriedad.
- Color de fondo: Azul muy claro (#EBF5FB), casi blanco, para un diseño limpio y agradable a la vista.
- Color de acento: Naranja (#F39C12) para resaltar elementos importantes y llamados a la acción.
- Tipografía: 'PT Sans', sans-serif, para asegurar legibilidad y claridad en la información presentada.
- Utilizar iconos claros y representativos para identificar los diferentes tipos de incidentes y acciones dentro de la aplicación.
- Diseño intuitivo y fácil de usar, con una navegación clara y una estructura lógica para facilitar la interacción de los usuarios.
- Animaciones sutiles para mejorar la experiencia del usuario, como transiciones suaves al cambiar entre secciones o al cargar nuevos datos.
